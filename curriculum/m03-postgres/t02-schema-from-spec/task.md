Turn a written spec into a PostgreSQL schema that enforces every rule itself. Application code changes; the database is the one place every write passes through.

## The spec

A team task tracker with four tables. Use exactly these table and column names; choose the types and constraint names yourself. Every `id` is generated by the database, and every `created_at` and `joined_at` defaults to the current time.

**`users`**: `id`, `email` (required, unique ignoring letter case), `display_name` (required, 1 to 80 characters), `created_at`.

**`teams`**: `id`, `name` (required, unique), `created_at`.

**`memberships`**: `team_id`, `user_id`, `role` (`owner` or `member`, default `member`), `joined_at`. A user is in a team at most once.

**`tasks`**: `id`, `team_id` (required), `title` (required, 1 to 200 characters), `status` (`todo`, `doing` or `done`, default `todo`), `assignee_id` (optional), `estimate_hours` (optional, greater than 0, fractions allowed), `due_on` (optional calendar date), `created_at`, `completed_at` (set exactly when the status is `done`).

Relationships:

- A task can only be assigned to a user who is a member of the task's team.
- Deleting a team deletes its memberships and tasks.
- Deleting a user deletes their memberships. Their tasks stay, unassigned.
- When a user leaves a team (their membership is deleted), their tasks in that team stay, unassigned. Their tasks in other teams are untouched.
- Every foreign key is backed by an index that starts with its columns.

## Submission

`schema.sql`, which creates everything on an empty database. Do not prefix names with a schema. Fill in the design notes in `README.md`.

## What is checked

The checks run `schema.sql` in a fresh schema and inspect the result: valid inserts and defaults, then inserts and updates that break each rule (they must fail with a constraint or data error, not because a column is missing), the delete behaviour above, and the catalog for primary keys and foreign-key indexes. The review looks at types, where each rule lives, and your notes.
